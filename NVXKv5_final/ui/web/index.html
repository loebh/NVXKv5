CHƯA KIỂM ĐỊNH
Thông số chia khối (blocking), căn chỉnh bộ nhớ 64B, thời gian chạy và sai số so với FP64 sẽ hiện tại đây.
MINH BẠCH DỮ LIỆU ĐO: Sơ đồ thanh ghi AVX2 bên dưới là [MÔ HÌNH THUẬT TOÁN] minh họa cấu trúc kernel thực của NVXK (không đọc trực tiếp thanh ghi phần cứng). Bên phải là [KẾT QUẢ THỰC TẾ] lấy trực tiếp từ hàm XK_plan_gemm(). Bộ đếm PMU phần cứng [KHÔNG KHẢ DỤNG] khi chạy không có quyền quản trị Intel PCM / perf.

NVXK Engineering Workbench — Hướng dẫn & Phím tắt

Offline CPU-only matrix multiplication workbench connected directly to NVXK v3.0 C++ core via local loopback HTTP (127.0.0.1). All telemetry is real; unsupported hardware PMU/thermal sensors are explicitly marked Unavailable.

Phím tắt nhanh
  • Ctrl+B — Chạy đo nhanh 256³ (tự nhận diện số nhân vật lý)
  • Ctrl+K — Chạy hiệu chuẩn phần cứng (~200 ms)
  • Alt+T — Đổi giao diện Sáng / Tối
  • ? — Mở bảng trợ giúp này; Esc — Đóng
