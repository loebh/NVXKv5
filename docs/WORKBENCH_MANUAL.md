# NVXK v3.0 Engineering Workbench Manual

Both the **Offline Web Workbench** (`nvxk_workbench.exe`, `ui/web/index.html`) and the **Native Dear ImGui Desktop App** (`nvxk_desktop.exe`, `ui/imgui/`) are fully implemented in NVXK v3.0 and share the C++17 `nvxk_workbench_engine` backend.

- See [Desktop & Web Workbench Guide](DESKTOP_GUIDE.md) for usage, keyboard shortcuts, Dark/Light themes, Generalized BLAS Quick-Tester, and live logs.
- See [Build Guide](BUILD_GUIDE.md) for enabling `-DNVXK_BUILD_DESKTOP_IMGUI=ON` with CMake.
